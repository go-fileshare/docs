v0.39.0부터 파일의 시간은 요청 시각이 아니라 해당 파일 시스템이 기록한
시간입니다. 이를 위해서는 `go-filesystems/interface` v0.6.0의 선택적 기능인
`TimesReader`가 필요하며, 드라이버가 이를 갖고 있을 수도 없을 수도 있습니다.

## 실제 시간을 알려 주는 공유 {#which-shares-report-real-times}

| 공유 | 실제 시간 |
|---|---|
| **디렉터리**(호스트) | 예: 접근, 수정, 변경, 그리고 호스트가 보관하는 경우 생성 시간. 나노초 단위 |
| **FAT 이미지** | 예, FAT의 해상도로: 수정 2초, 접근 1일, 생성 10ms. 변경 시간은 없음 |
| **exFAT 이미지**(v0.40.0부터) | 예: 생성과 수정 10ms, 접근 2초. 변경 시간은 없음 |
| **NTFS 이미지**(v0.40.0부터) | 예: 생성, 수정, 변경, 접근. 100ns |
| **ext4 이미지**(v0.40.0부터) | 예: 접근, 수정, 변경은 1ns(ext2/ext3의 128바이트 inode에서는 1초). 생성 시간은 inode가 충분히 클 때만 |
| **HFS+ 이미지**(v0.40.0부터) | 예: 생성, 수정, 변경, 접근. 1초 |
| 그 밖의 이미지 형식 | 이전처럼 응답 |
| 사용자 본인으로 제공되는 공유(`remote` 워커) | 예, 워커의 디렉터리가 호스트 디렉터리인 경우: 시간이 워커 경계를 넘어 전달됨 |

시간은 형식의 해상도와 프로토콜의 해상도 중 **더 거친 쪽**으로 비교됩니다.
SFTP는 정수 초, WebDAV의 `getlastmodified`도 정수 초, SMB는 100ns, NFS는
1ns입니다.

## 시간이 기록되지 않았을 때 {#when-a-time-is-not-recorded}

| 프로토콜 | 전송되는 값 |
|---|---|
| **SMB** | 0(「지정되지 않음」). 이 기능이 없는 드라이버는 여전히 현재 시각을 답합니다. |
| **NFS** | 접근 시간이나 변경 시간이 없으면 수정 시간이 되고, 수정 시간이 없으면 서버 시작 시각이 됩니다. |
| **SFTP** | 수정 시간이 없으면 `ACMODTIME` 플래그를 지웁니다. 클라이언트는 잘못된 시간 대신 시간 없음으로 봅니다. |
| **WebDAV** | `creationdate`는 생성 시간입니다. 기록되지 않은 시간은 응답에 나타나지 않습니다. |

## SMB에서 클라이언트가 설정하는 시간 {#setting-times}

v0.41.0부터(`go-filesystems/smb` v0.10.0,
go-filesystems/smb#45) 클라이언트가 SMB로 설정한 접근 시간과 수정 시간
(`SET_INFO`. `touch`, `robocopy /COPY:T`, 탐색기에서의 복사가 하는 동작)이
**디렉터리** 공유의 파일에 적용됩니다. 값이 0인 시간은 그대로 둡니다. -1은 그
시간을 고정하고 -2는 다시 재개합니다(열린 핸들마다).

저장할 수 없는 시간은 **기본적으로 무시됩니다**. 요청은 성공하고 해당 필드만
버려집니다(Samba와 같은 동작이며, 시간을 보존하는 복사가 실패하지 않게 하기
위해서입니다). 대상은 생성 시간, 단독으로 전송된 변경 시간, 시간을 설정할 수
없는 드라이버의 모든 시간입니다. fileshare에는 이를 위한 설정이 없으며 모든
공유가 기본값을 사용합니다.

### 동작 선택: `unstorable_times` {#unstorable-times}

v0.42.0부터 공유마다 `unstorable_times`로 이런 시간을 어떻게 처리할지 정할 수
있습니다(`go-filesystems/smb`의 `UnstorableTimes` 옵션).

```hcl
share "attic" {
  directory        = "/srv/attic"
  unstorable_times = "refuse"   # "ignore"(기본값), "refuse", "log"
}
```

| 값 | 클라이언트가 받는 응답 | 유지되는 것 |
|---|---|---|
| `ignore`(설정이 없을 때도) | 성공 | 해당 필드는 버려짐(Samba와 동일) |
| `refuse` | `STATUS_NOT_SUPPORTED`. 백업 도구가 시간이 보존되었다고 오해하지 않도록 하기 위함 | 해당 요청의 내용은 아무것도 적용되지 않음 |
| `log` | 성공 | 해당 필드는 버려지고, 요청마다 공유 이름, 경로, 필드를 적은 한 줄이 서버가 자신의 줄을 쓰는 곳에 기록됨 |

그 밖의 값은 구성을 읽을 때 공유 이름과 세 가지 값을 밝히는 오류로 거부됩니다.
이 설정은 SMB의 것입니다. `protocols`에 SMB가 빠진 공유가 이를 설정하면
거부됩니다. 서버 전체의 기본값은 없으며 공유마다 지정합니다. 관리 API로 만든
공유는 `ignore`를 사용합니다.
