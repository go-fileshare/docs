v0.39.0 から、ファイルの時刻はリクエスト時刻ではなく、そのファイルシステムが
記録した時刻になります。これには `go-filesystems/interface` v0.6.0 の任意機能
`TimesReader` が必要で、ドライバーが持っている場合と持っていない場合があります。

## 実際の時刻を返す共有 {#which-shares-report-real-times}

| 共有 | 実際の時刻 |
|---|---|
| **ディレクトリ**(ホスト) | はい: アクセス、更新、変更、ホストが保持していれば作成時刻。ナノ秒単位 |
| **FAT イメージ** | はい。FAT の分解能で: 更新 2 秒、アクセス 1 日、作成 10 ミリ秒。変更時刻はありません |
| **exFAT イメージ**(v0.40.0 以降) | はい: 作成と更新 10 ミリ秒、アクセス 2 秒。変更時刻はありません |
| **NTFS イメージ**(v0.40.0 以降) | はい: 作成、更新、変更、アクセス。100 ナノ秒 |
| **ext4 イメージ**(v0.40.0 以降) | はい: アクセス、更新、変更は 1 ナノ秒(ext2/ext3 の 128 バイト inode では 1 秒)。作成時刻は inode が十分大きい場合のみ |
| **HFS+ イメージ**(v0.40.0 以降) | はい: 作成、更新、変更、アクセス。1 秒 |
| その他のイメージ形式 | 従来どおり応答します |
| 本人として提供される共有(`remote` ワーカー) | はい。ワーカーのディレクトリがホストのディレクトリの場合: 時刻はワーカーの境界を越えます |

時刻は、形式の分解能とプロトコルの分解能の**粗い方**で比較されます。SFTP は
整数秒、WebDAV の `getlastmodified` も整数秒、SMB は 100 ns、NFS は 1 ns です。

## 時刻が記録されていないとき {#when-a-time-is-not-recorded}

| プロトコル | 送られる値 |
|---|---|
| **SMB** | 0(「未指定」)。この機能を持たないドライバーは、従来どおり現在時刻を返します。 |
| **NFS** | アクセス時刻または変更時刻がない場合は更新時刻になり、更新時刻がない場合はサーバーの起動時刻になります。 |
| **SFTP** | 更新時刻がない場合は `ACMODTIME` フラグを消します。誤った時刻ではなく、時刻なしとして見えます。 |
| **WebDAV** | `creationdate` は作成時刻です。記録されていない時刻は応答に含まれません。 |

## SMB でクライアントが設定する時刻 {#setting-times}

v0.41.0 から(`go-filesystems/smb` v0.10.0、
go-filesystems/smb#45)、クライアントが SMB で設定したアクセス時刻と更新時刻
(`SET_INFO`。`touch`、`robocopy /COPY:T`、エクスプローラーでのコピーが行う操作)
が、**ディレクトリ**共有のファイルに反映されます。値が 0 の時刻はそのまま
です。-1 はその時刻を固定し、-2 で再開します(開いているハンドルごと)。

保存できない時刻は**既定では無視されます**。要求は成功し、そのフィールドだけが
捨てられます(Samba と同じ動作で、時刻を保つコピーが失敗しないようにするため
です)。対象は、作成時刻、単独で送られた変更時刻、時刻を設定できないドライバー
上のすべての時刻です。fileshare にはこのための設定はなく、すべての共有が既定を
使います。

### 動作を選ぶ:`unstorable_times` {#unstorable-times}

v0.42.0 から、共有ごとに `unstorable_times` でこの種の時刻の扱いを指定できます
(`go-filesystems/smb` の `UnstorableTimes` オプション)。

```hcl
share "attic" {
  directory        = "/srv/attic"
  unstorable_times = "refuse"   # "ignore"(既定)、"refuse"、"log"
}
```

| 値 | クライアントに返る応答 | 保持されるもの |
|---|---|---|
| `ignore`(設定がない場合も) | 成功 | そのフィールドは捨てられる(Samba と同じ) |
| `refuse` | `STATUS_NOT_SUPPORTED`。バックアップツールが時刻を保持できたと誤解しないようにするため | その要求の内容は何も適用されない |
| `log` | 成功 | そのフィールドは捨てられ、要求ごとに共有名、パス、フィールドを記した 1 行が、サーバー自身の出力先に書かれる |

これ以外の値は、設定の読み込み時に、共有名と 3 つの値を示すエラーで拒否されます。
この設定は SMB のものです。`protocols` が SMB を含まない共有でこれを設定すると
拒否されます。サーバー全体の既定値はなく、共有ごとに指定します。管理 API で作成した
共有は `ignore` になります。
