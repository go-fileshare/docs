認証情報は、提示されたときに検査されます。その後で人を取り消すこと、つまり退職したスタッフ、
go-authn/bridge で無効化されたアカウント、停止された IdP 全体の取り消しは、その人に与えられた
**すべての**認証情報と、それらがすでに開いたセッションに及ぶ必要があります。ここにある認証情報の種類ごとに
異なる仕組みで取り消すのは、発行方法も検査方法もそれぞれ異なるためです。

| 認証情報 | プロトコル | 取り消す仕組み | 追加時期 |
|---|---|---|---|
| `users` ディレクトリ(SQL、LDAP)内のパスワード、NT ハッシュ、アプリケーションパスワード | SMB、WebDAV、S3 | 行を削除し、[ディレクトリの再読み込み]({{< relref "/administration/reload.md" >}})を行う。新しい世代となり、それが開いた接続は閉じられる | v0.10.0 |
| 共有の権限付与 | すべてのプロトコル | [管理 API]({{< relref "/administration/_index.md" >}})の `Revoke` または `DisableShare`。新しい世代となり、接続は閉じられる | v0.8.0 |
| プロバイダーの CA が署名した SSH 証明書 | SFTP | その [KRL]({{< relref "/security/revocation-lists.md" >}})(ログイン時と**すべての操作**で検査)、および[共有シグナル]({{< relref "/security/shared-signals.md" >}}) | v0.12.0、v0.13.0 |
| OpenPubkey(opkssh)証明書 | SFTP | どのリストにも載せられない。[共有シグナル]({{< relref "/security/shared-signals.md" >}})と `opkssh_max_age` | v0.13.0 |
| アクセストークン | WebDAV | どのリストにも載せられない。[共有シグナル]({{< relref "/security/shared-signals.md" >}}) | v0.13.0 |
| 人を名指しする X.509 クライアント証明書 | NFS | その [CRL]({{< relref "/security/nfs-certificates.md#revocation-the-crl" >}})(次の呼び出しで検査)、および[共有シグナル]({{< relref "/security/shared-signals.md" >}}) | v0.12.0、v0.13.0 |

3 列目の仕組みがなければ、認証情報は期限が切れるまで有効なままです。証明書やトークンでは、
その期間がその有効期間になります。

## そのすべてがフェイルクローズ {#every-one-of-them-fails-closed}

取得できない失効リスト、`max_age` より古いコピー、自身の `NextUpdate` を過ぎた CRL、`max_age` 以内に応答のない
共有シグナルのトランスミッター。これらのどれも「何も失効していない」とは解釈されません。「このサーバーは
知らない」であり、その仕組みが管理する認証情報は、再び知るまで**拒否されます**。

{{< callout type="error" >}}
**代価は可用性であり、それは意図的に支払われます**

リストに到達できないときにすべてを通す失効チェックは、リストをブロックできる攻撃者に破られるものです。
ブラウザーのソフトフェイルな OCSP が「衝突したときに切れるシートベルト」と呼ばれたのと同じ理由です。
そのため、リストやトランスミッターは、それが管理するログインと同じ信頼性で提供されなければならず、
それが古くなりつつあることを示すメトリクスが[アラートの対象]({{< relref "/administration/health.md#what-to-alert-on" >}})となるものです。
{{< /callout >}}

コピーが置き換えられるのは、解析に成功したリストによってのみです。壊れた状態で届いたリストは、
最後の正常なものをそのまま残し、それが取得された時点から `max_age` に向けて数え続けられます。
また、リストは **HTTPS のみ**で取得されます。経路上の攻撃者が差し替えられるリストは何も失効させないため、
平文 HTTP の URL は起動時に拒否されます。

## トランスポート {#transport}

認証情報そのものが、平文でネットワークを横切ってはなりません。それが
[TLS]({{< relref "/security/tls.md" >}})です。TLS 上の WebDAV、S3、NFS、ファイルまたは ACME による証明書、
そして v0.9.0 以降は、**パスワードを使う WebDAV の平文提供の拒否**です。
